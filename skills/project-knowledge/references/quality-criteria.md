# 语义与检索验收

只在交付前读取。格式、覆盖和 reviewer 规则分别由 OKF 契约、coverage validator 与审查契约判定；本文件只检查知识是否真的能回答问题。

## 语义

- 关键结论由适用版本和权威范围足够的来源支持；当前、历史、计划、推断、冲突和未知明确区分。
- `active` 未被更高权威来源推翻；`superseded` / `deprecated` 说明原因并指向当前结论。
- 页面回答真实问题并包含边界、失效条件和带语义的强关系；标题页、目录复述和模板空话不通过。
- 同一稳定身份只有一个规范页；原始来源、当前综合结论和历史版本通过关系连接，不复制成多个“当前事实”。
- 本次变化已同步受影响的概念、强关系、索引和日志；未知用户内容与原始版本得到保留。
- 答案与里程碑声明只使用 `done` 来源支撑的事实，并列出相关 pending、not_verified、blocked 和 review 缺口。

## 真实检索

使用 3–5 个不含文件名提示的问题，至少覆盖：

1. 精确事实；
2. 跨页面关系；
3. 旧版本、替代项或冲突；
4. 没有可靠答案，期望返回缺口。

个人库还要返回相似项目经验及适用边界；项目库还要指导关键任务并定位当前契约；产品库还要返回相关能力、需求、迭代、决策、来源和可追溯需求上下文包。只对通过这些问题及里程碑 review 的问题范围声明 operational。
