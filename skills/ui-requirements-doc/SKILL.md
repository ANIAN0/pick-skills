# UI 需求文档

把用户希望通过界面完成的事情聊清楚，并写成一份设计师和原型开发者可以独立理解的 UI 需求正文。

正文只保留当前已经形成的 UI 结论。正文旁使用同名二级目录保存变更日志，以及确有保留价值的讨论、问题和审查材料。

## 核心原则

- 根据实际界面和协作需要组织正文，不使用固定模板、页面类型、字段表或检查清单代替判断。
- 只写会影响页面设计和交互理解的内容。业务背景可以简述或链接已有需求，不重复改写完整业务需求。
- 页面简单就简短说明；页面复杂、多页面协作或存在关键状态时再展开。
- 正文应让不了解本次对话的设计师和原型开发者理解用户要完成什么、界面如何承载、主要操作如何发生，以及重要结果如何反馈。
- 只追问会导致页面结构、信息内容、操作方式或关键状态产生明显不同设计的问题。
- 明确区分材料事实、已经确认的 UI 结论和仍然不确定的内容，不把推测写成已确定需求。
- 审查问题只用于发现表达缺口，不是新的需求来源。正文中的每项新增结论都必须能追溯到用户表达、输入材料或项目事实，不能用“常见做法”“首版默认”或主 agent 的偏好补全需求。

## 工作方式

先理解用户要通过界面完成的任务，再按需查看直接相关的业务需求、现有页面、前端代码、截图、设计规范和项目约束。正式需求文档只是可选输入；用户描述或现有界面已经足够时可以直接开始。

围绕当前事项自然聊清页面范围、页面之间的关系、需要呈现的信息、用户能够执行的操作、操作反馈以及真正重要的异常或边界。权限、可见性、响应式、文案和视觉强调只有在影响本次设计时才写。不要为了形式完整穷举所有控件状态。

尽早创建或更新正文，并随讨论持续合入结论。正文可以按用户任务、页面、流程或信息结构组织，以最容易理解为准，不预设章节。页面、字段、操作、弹窗和状态等内容适合表格时使用表格，连续过程更适合文字时直接叙述。

为每个独立事项使用稳定的工作名称，并尽量采用简短、明确的中文名称；已有事项编号时使用“编号-中文功能名”。路径优先遵循用户或项目现有约定，否则写入 `workplace/<版本>/ui-requirements/<工作名称>.md`。正文旁建立同名二级目录，维护独立的 `变更记录.md`，并按需保存审查问题等过程材料。正文含义发生变化时简要记录改了什么以及为什么；纯排版和错字修改不必记录。

如果存在相关业务需求或其他输入文档，在正文开头直接列出真实文件链接。不同阶段依靠明确链接建立关系，不根据相似文件名猜测。没有正式需求文档时不创建虚假链接。

正文必须能够独立表达当前 UI 结论。过程材料中形成的最终结论要合入正文，不让设计师或原型开发者依赖审查记录才能理解要做什么。

## 清晰度审查

主 agent 认为正文已经能够表达 UI 需求后，使用两个新的 subagent 检查它是否真的可以独立传达这份理解：

1. 只把 UI 需求正文交给第一个 subagent，不提供用户对话、输入材料或主 agent 的预期答案。让它以接手设计或制作原型的人员视角，提出至少 10 个有价值、能够检验 UI 理解的问题；不得用同义问题或无关细节凑数。
2. 只把正文和问题交给第二个 subagent，同样不提供其他上下文。让它完全根据正文逐题回答；正文无法支持答案时明确写“不确定”，不能自行补全。
3. 主 agent 根据完整输入和已经形成的 UI 理解独立回答这些问题，再与第二个 subagent 的答案比较，只比较含义，不比较措辞。
4. 如果差异会导致页面范围、信息结构、主要操作、页面流转或关键状态产生不同设计，先回到原始输入查证。能查证时修改正文；无法查证时询问用户或明确保留为未确定事项，不能自行选择答案。记录语义变更后再重新审查。
5. 如果差异只涉及视觉设计师可以自行决定的细节，或用户尚未定义且不影响当前界面的内容，不为了让答案完全一致而扩写正文。

把每轮问题、回答和有意义的差异保存在同名二级目录的 Markdown 文件中。不要把审查过程、“审查通过”或固定完成状态写进正文，也不要提前向两个 subagent 泄露主 agent 的理解。

审查中出现大量“不确定”并不等于正文必须扩写。只有会让设计师或原型开发者对已经确定的需求产生错误理解，才需要补充正文；属于设计自由度、实现细节或尚未作出的产品决定时，保持简洁并如实说明。

## 边界

- 不要求先执行 `project-requirements`，也不强制先存在 PRD 或需求文档。
- 不生成 HTML、图片、Figma、Axure 或其他原型，不实现生产前端代码。
- 不决定像素级视觉风格、组件库实现或技术架构；已有设计规范可以作为约束引用。
- 不用固定章节、页面类型、字段清单、状态机或额外确认门槛衡量完整性。
- 不把 UI 需求文档写成业务需求副本、技术方案或验收报告。
