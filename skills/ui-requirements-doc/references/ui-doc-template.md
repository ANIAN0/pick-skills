# UI 需求文档模板

每个页面文档使用以下结构：

```markdown
# [页面名称] UI需求文档

## 1. 页面概述
**页面类型**：[list/form/detail/dashboard]
**用途说明**：[简述页面功能]
**入口路径**：[如何访问此页面]

## 2. 页面布局
### 2.1 整体结构
### 2.2 区块划分

| 区块名称 | 位置 | 内容说明 |
|---|---|---|
| 搜索区 | 顶部 | 筛选条件输入 |
| 数据区 | 中央 | 表格数据展示 |
| 操作区 | 右侧 | 操作按钮列 |

## 3. 字段详情
### 3.1 搜索字段

| 字段名称 | 字段类型 | 是否必填 | 备注 |
|---|---|---|---|

### 3.2 表格列/表单字段

| 字段名称 | 字段类型 | 是否必填 | 备注 |
|---|---|---|---|

### 3.3 详情信息

| 信息项 | 展示方式 | 数据来源 |
|---|---|---|

## 4. 交互行为
### 4.1 主要操作

| 操作名称 | 触发方式 | 结果说明 |
|---|---|---|
| 新建 | 点击按钮 | 打开新建弹窗 |
| 编辑 | 点击操作列 | 打开编辑抽屉 |
| 删除 | 点击按钮 | 确认后删除 |

### 4.2 流程说明
[描述关键业务流程的用户操作步骤]

## 5. 弹窗/抽屉

### 5.1 [弹窗名称]
- **触发方式**：[如何打开]
- **尺寸建议**：[宽度x高度]
- **内容结构**：[标题、字段、按钮]

## 6. 提示信息
### 6.1 操作反馈
- 成功提示：[成功文案]
- 失败提示：[失败文案]
- 删除确认：[确认文案]

### 6.2 状态提示
- 空数据：[空状态文案]
- 加载中：[加载提示]
- 错误：[错误提示]
```

字段类型优先使用：文本输入、数字输入、下拉选择、单选、多选、日期选择、开关/切换、文件上传、富文本、只读文本、状态标签。
